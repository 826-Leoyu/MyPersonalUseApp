# MyPersonalUseApp

一个自用的每日任务规划 App：每天一页自由画布，任务卡片可以随意拖动，两张卡片碰一下就能连线，完成或删除只需把卡片拖到屏幕底部。

- **技术栈**：Flutter
- **平台**：Windows、Android（第一阶段）→ iOS（第二阶段，通过 Codemagic 云端编译）
- **设计文档**：[`docs/DESIGN.md`](docs/DESIGN.md)
- **任务跟踪**：[GitHub Issues](https://github.com/826-Leoyu/MyPersonalUseApp/issues)
