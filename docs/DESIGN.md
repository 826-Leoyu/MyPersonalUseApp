# 设计文档：个人每日任务画布 App

> 来源：2026-10-19 的 grilling 需求访谈，以及 spec 审阅中确认的修改（标注 spec v2 / v3）。以下所有条目都已由用户确认。实现细节以 `docs/specs/0001-daily-canvas-mvp.md` 为准。

## 1. 基本信息

| 项目 | 决定 |
|---|---|
| 用途 | 只给自己用，规划每天的任务 |
| 技术 | Flutter，一套代码支持多个平台 |
| 平台顺序 | 第一阶段：**Windows + Android**；第二阶段：用 Codemagic 云端编译 iOS 版（没有 Mac），安装方式（免费 Apple ID + AltStore，或 99 美元/年的 TestFlight）到时再定 |
| 数据 | 第一版只存在本地，数据结构按以后能同步来设计；第二版接入 Supabase 同步 |
| 界面语言 | 中文 |

## 2. 视觉风格（仿 Apple 备忘录）

- 米白色纸张背景，**没有点阵**
- 卡片是圆角，带轻微阴影，**默认淡黄色**
- 先用系统字体，以后加字体选择
- 开发前先做一个**可以点击的原型**，确认外观后再继续

## 3. 画布与日期

- **每天一页**自由画布，可以平移，双指缩放
- 顶部有日期栏：左右滑动日期栏或点 ◀ ▶ 切换日期，可以提前规划以后的日子（画布本身的滑动不用来切换日期）
- 日期用英文月份缩写显示：标题 `Tue, Oct 20, 2026`，其他地方 `Oct 20`（不是今年时加年份）（spec v3）
- 过去的日期只能查看，不能新建卡片（spec v3）
- **顺延**：没完成的任务在第二天打开时，按原来的相对位置和连线整体放到当天画布的左上角，标上"顺延"；当天已有的卡片自动往右移，避免重叠
- 顺延时**卡片本身搬到今天**，原来那天在原位置留下一条只读、半透明的历史记录（"已顺延至 Oct 20"），点它跳到卡片现在所在的日期；任何时候都只有一张有效卡片（spec v2）

## 4. 任务卡片

- 内容：标题（必填）、可选的备注、可以调整大小；卡片上只显示备注的第一行，超出用省略号（spec v2）
- 点击：单击选中，再单击编辑，双击完成（spec v2）
- 颜色：长按卡片（Windows 上右键）弹出菜单（改颜色、编辑、删除），选"改颜色"打开约 8 种柔和色板（淡黄为默认，另有淡粉、淡绿、淡蓝、淡紫、淡灰等），另外有"自定义"调色盘；文字根据背景深浅自动变成黑色或白色
- 移动：按住卡片拖动；在空白处拖动是平移画布

## 5. 连线（碰撞交互）

- 把卡片拖到另一张卡片上**停留约 0.4 秒**，目标卡片放大发光，同时预览结果（虚线表示要连线，✂️ 表示要断开），**松手才执行**，手机上会轻微振动确认
- 停留时间不到就移开，什么都不会发生（防止拖动时路过其他卡片造成误碰）
- 碰撞一次连线，再碰撞一次断开；也可以单击连线，再点中点出现的 ✂️ 断开，Windows 上还可以右键连线选"断开连线"（spec v2）
- 执行后被拖的卡片**弹回原来的位置**
- 方向：**被拖的卡片在前，被碰的卡片在后**，线上有细箭头
- 一张卡片可以连多条线（可以分叉、汇合）
- 线是平滑的贝塞尔曲线，自动从两张卡片最近的边连出去，卡片移动时实时跟随；连线时有"画出来"的动画，断开时淡出
- 现在线只是视觉效果，数据里已经记下方向和类型，以后可以升级成**依赖关系**和**时间轴**

## 6. 完成与删除

- 拖动卡片时屏幕底部出现两个区域：**✅ 完成**（左）和 **🗑️ 回收站**（右）；双击卡片也能快速完成
- 完成的任务保留历史记录，以后可以做统计
- 删除的卡片进入**回收站，保留 10 天**，期间可以恢复（如果原来连着的卡片还在，线也一起恢复），超过 10 天永久删除

## 7. Windows 快捷键（spec v2）

- Delete/Backspace 删除、Enter 编辑、Ctrl+Enter 完成、Ctrl+N 新建、←/→ 切换日期、T 回到今天、Esc 取消
- Ctrl+Z 撤销移动、完成、删除、连线/断开，切换日期或重启后清空
- 编辑文字时这些快捷键不干扰打字
