# 日程便签 App UI 参考素材 / UI reference pack

这套素材来自当前对话中提供的同一张布局示意截图，**不是两套独立的平台 UI**。`android/` 和 `windows/` 只是**同一自适应布局在窄屏、宽屏状态下的视觉片段**，目录名称仅用于分类；不能将目录当作平台判断条件。

## 文件

- `shared/responsive_planner_original.png`：完整参考截图，唯一主要视觉基准。
- `android/compact_canvas_reference.png`：从原截图裁出的窄屏便签画布局部；**顶部原本已经被截图裁掉**，不可当作完整 Android 页面布局规范。
- `windows/expanded_sidebar_reference.png`：从原截图裁出的宽屏侧栏 + 画布局部；底边可能不完整，不包含可实现的窗口标题栏规范。

## 设计目标：One UI, Adaptive Layout

- Android、Windows 共用 **同一个 Planner Screen、Header、Sidebar/Date Navigation、自由便签画布、Note Card 视觉系统**。
- UI 模式由 **LayoutBuilder / MediaQuery 中的可用逻辑宽度** 决定，而不是仅根据 `Platform.isAndroid` / `Platform.isWindows` 做布局分支。必要时应根据可用画布宽度、窗口缩放、字体大小一起调整。
- 建议以 **840 logical pixels** 作为初始试验断点（不是不可变的固定要求）：
  - **窄窗口**（小于 840dp）：日期栏默认隐藏，以左侧抽屉 overlay 到画布上；从左边缘右滑或点击日历图标可打开；可左滑、点击外部、返回键关闭。
  - **宽窗口**（840dp 或以上）：左侧日期栏默认展开且可折叠；右侧画布填满剩余空间。可折叠时仍可通过相同的日历/菜单按钮展开。
  - 在断点附近反复调整窗口宽度时应稳定，不丢失日期选择、输入焦点和便签状态。
- 同一份布局适用于窄 Windows 窗口和宽 Android 平板，而不跟 OS 绑定。鼠标右键、双击、快捷键等只是输入方式增强；不要让它们造成两套业务界面。

## 视觉规范（参考值，按现有主题适当微调）

- 背景：极浅灰白 `#F5F5F7`，内容表面 `#FFFFFF`；避免过度阴影。
- 便签：暖黄 `#FFF0B8`、浅蓝 `#DBEBFF`；可扩展浅绿、浅粉等柔和颜色。
- 强调按钮：暖金黄 `#D9A441`，主文色接近 `#1C1C1E`。
- 便签边角：约 16–20dp；侧栏和面板边角：约 16–24dp；间距用统一 4/8dp spacing tokens。
- 简洁单行页头，左侧日历/侧栏开关，中间选中日期，右侧操作。
- 白底、留白、低对比度分隔线、清楚的选中日期高亮、简洁的悬浮新增按钮。
- 这是**视觉与交互参考**，不是要求屏幕上每个便签的位置和尺寸 1:1 固定。

## 保留现有功能和避免回归

- 保留原有日期状态单一数据源、日期切换、午夜维护、撤销/重做及自动保存行为。
- 保留便签自由坐标、拖动、缩放、层级和数据库数据。布局变化时**不得无意修改已保存的卡片坐标/尺寸**，并处理窗口变窄导致的便签暂时离开视口问题（例如视口平移、可见区域提示或按需滚动），不要隐式重写数据。
- 狭窄状态的抽屉手势只能使用适当的边缘触发区域，不得抢占便签拖动/缩放、Android 系统返回手势。
- Windows 的 title bar 由现有窗体框架决定，截图里仿造的标题栏只是概念示意；不要无故重写原生窗口标题栏。
- 深色主题、字号缩放、屏幕方向变化和 Windows 窗口任意缩放需验证。
